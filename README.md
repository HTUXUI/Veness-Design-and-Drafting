# Veness Design & Drafting website

Static site (Black Editorial direction). No framework.

```
npm start        # builds to dist/ and serves http://localhost:4173
npm run build    # builds to dist/
```

- Pages and templates: `build.mjs`
- Copy for Meet Chris and client stories: `src/data/content.mjs`
- Project image groups: `src/data/collections.json`, generated by `python scripts/prepare-images.py "<IMAGERY folder>"`
- Styles and behaviour: `src/styles.css`, `src/main.js`

Placeholders still to replace before launch are marked on the pages (project briefs, privacy wording). The enquiry form needs a server endpoint (`data-endpoint` or `window.VENESS_ENQUIRY_ENDPOINT`).
